# Prints das operações

Salve aqui as capturas de tela com estes nomes (o README.md já aponta para eles):

| Arquivo | O que capturar |
|---|---|
| `01-inserir.png` | Formulário "Novo produto" preenchido **ou** a mensagem verde "Produto #X cadastrado com sucesso" |
| `02-listar.png` | Grade com vários produtos (use "Carregar exemplos") |
| `03-buscar.png` | Resultado da busca por ID (título "Resultado da busca: ID X") |
| `04-atualizar.png` | Formulário "Editando produto #X" |
| `05-excluir.png` | Caixa de confirmação de exclusão |
| `06-lixeira.png` | Modo "Ver lixeira" com a coluna "Excluído em" |

O mínimo exigido são três operações; seis deixam a entrega completa.
Atalho no Windows: **Win + Shift + S** para recortar só a janela.
